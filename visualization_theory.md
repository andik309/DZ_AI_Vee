# Визуализация данных — шпаргалка

## 1. Подключение библиотек

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

data = pd.read_csv(
    "school_progress.csv",
    index_col="enrollment_id"
)
```

- `matplotlib.pyplot` — базовые инструменты для построения и настройки графиков.
- `seaborn` — библиотека поверх Matplotlib, которая упрощает построение статистических графиков по `DataFrame`.

---

## 2. Из чего состоит график

В Matplotlib полезно различать два объекта:

- **Figure** — всё изображение целиком.
- **Axes** — отдельное поле, на котором строится один график.

```python
fig, ax = plt.subplots()
```

`fig` отвечает за изображение целиком, `ax` — за конкретный график.

Простой вариант без явной работы с `Axes`:

```python
plt.plot(x, y)
plt.show()
```

---

## 3. Линейный график: `plot()`

Линейный график показывает, как значение меняется при движении по оси `x`.

```python
plt.plot(x, y)
```

Чаще всего подходит для:

- времени;
- последовательных измерений;
- упорядоченных значений.

Пример:

```python
grade_score = (
    data.groupby("grade")["average_score"]
    .mean()
)

plt.plot(
    grade_score.index,
    grade_score.values
)
```

Здесь:

- `x` — классы;
- `y` — средний балл.

### Внешний вид линии

```python
plt.plot(
    x,
    y,
    linestyle="--",
    marker="o",
    linewidth=2
)
```

- `linestyle` — вид линии;
- `marker` — значок в точках;
- `linewidth` — толщина линии.

Основные стили:

```text
"-"   сплошная
"--"  штриховая
":"   пунктирная
"-."  штрихпунктирная
```

---

## 4. Заголовок, подписи, сетка и легенда

### Заголовок

```python
plt.title("Средний балл по классам")
```

### Подписи осей

```python
plt.xlabel("Класс")
plt.ylabel("Средний балл")
```

### Сетка

```python
plt.grid(True)
```

Сетка помогает точнее сравнивать значения по осям.

### Легенда

Сначала графику задают `label`:

```python
plt.plot(x, y, label="Средний балл")
```

Затем показывают легенду:

```python
plt.legend()
```

Легенда нужна, когда на одном поле изображено несколько наборов данных.

---

## 5. Размер изображения

```python
plt.figure(figsize=(10, 5))
```

`figsize=(ширина, высота)` задаёт размер изображения.

При работе через `subplots()`:

```python
fig, ax = plt.subplots(
    figsize=(10, 5)
)
```

## 6. Столбчатая диаграмма: `bar()` и `barh()`

Столбчатая диаграмма нужна для **сравнения отдельных категорий**.

Например, сравнить количество записей по курсам:

```python
counts = data["course"].value_counts()

plt.bar(
    counts.index,
    counts.values
)
```

- первый аргумент — названия категорий;
- второй — высота столбцов.

Горизонтальная версия:

```python
plt.barh(
    counts.index,
    counts.values
)
```

`barh()` удобен, если названия категорий длинные.

---

## 7. Гистограмма: `hist()`

Гистограмма показывает **распределение числового признака**.

Она отвечает на вопросы:

- где находится большинство значений;
- насколько сильно значения разбросаны;
- есть ли редкие очень большие или маленькие значения.

```python
scores = (
    data["average_score"]
    .dropna()
)

plt.hist(
    scores,
    bins=10
)
```

`bins` — количество интервалов, на которые разбивается диапазон значений.

Например:

```text
50–55
55–60
60–65
...
```

Высота столбца показывает, сколько наблюдений попало в этот интервал.

---

## 8. Диаграмма рассеяния: `scatter()`

`scatter()` показывает связь между **двумя числовыми признаками**.

```python
plt.scatter(
    data["hours_spent"],
    data["average_score"]
)
```

Каждая точка — одна строка таблицы.

Здесь:

- координата `x` — `hours_spent`;
- координата `y` — `average_score`.

По графику можно заметить:

- растёт ли один признак вместе с другим;
- уменьшается ли;
- есть ли группы точек;
- есть ли необычные значения.

### Размер и прозрачность точек

```python
plt.scatter(
    x,
    y,
    s=40,
    alpha=0.5
)
```

- `s` — размер точки;
- `alpha` — прозрачность от `0` до `1`.

Прозрачность полезна, когда точки накладываются друг на друга.

---

## 9. Несколько графиков: `subplots()`

Если нужно показать несколько графиков отдельно, удобно создать сетку:

```python
fig, axes = plt.subplots(
    1,
    2,
    figsize=(12, 5)
)
```

Это создаёт:

```text
[ график 1 ] [ график 2 ]
```

Первое поле:

```python
axes[0].hist(
    data["average_score"].dropna()
)
```

Второе:

```python
axes[1].scatter(
    data["hours_spent"],
    data["average_score"]
)
```

Заголовок отдельного поля:

```python
axes[0].set_title("Распределение баллов")
```

Подписи:

```python
axes[0].set_xlabel("Балл")
axes[0].set_ylabel("Количество")
```

Для сетки `2 × 2`:

```python
fig, axes = plt.subplots(
    2,
    2,
    figsize=(12, 8)
)

axes[0, 0]
axes[0, 1]
axes[1, 0]
axes[1, 1]
```

## 10. Seaborn: `data`, `x`, `y`

Seaborn умеет брать данные прямо из `DataFrame`.

```python
sns.scatterplot(
    data=data,
    x="hours_spent",
    y="average_score"
)
```

- `data` — таблица;
- `x` — столбец для горизонтальной оси;
- `y` — столбец для вертикальной оси.

То есть не нужно отдельно писать:

```python
x = data["hours_spent"]
y = data["average_score"]
```

## 11. Дополнительная информация: `hue`, `style`, `size`

На одном графике можно показать больше двух признаков.

### `hue` — цвет

```python
sns.scatterplot(
    data=data,
    x="hours_spent",
    y="average_score",
    hue="level"
)
```

Каждый уровень `level` получит свой цвет.

### `style` — форма точки

```python
sns.scatterplot(
    data=data,
    x="hours_spent",
    y="average_score",
    style="status"
)
```

Разные значения `status` будут обозначены разными маркерами.

### `size` — размер точки

```python
sns.scatterplot(
    data=data,
    x="hours_spent",
    y="average_score",
    size="lessons_completed"
)
```

Размер точки будет зависеть от `lessons_completed`.

Можно использовать параметры вместе:

```python
sns.scatterplot(
    data=data,
    x="hours_spent",
    y="average_score",
    hue="level",
    style="status"
)
```

Добавлять слишком много признаков одновременно не стоит: график становится труднее читать.

---

## 12. `countplot()` — количество объектов в категориях

`countplot()` сам считает, сколько строк относится к каждой категории.

```python
sns.countplot(
    data=data,
    x="status"
)
```

Получаем количество:

```text
active
completed
dropped
```

Дополнительное разделение:

```python
sns.countplot(
    data=data,
    x="status",
    hue="level"
)
```

Теперь внутри каждого статуса данные разделены по `level`.

`countplot()` используется, когда нужен именно **размер категории**, а не среднее числового признака.

---

## 13. `barplot()` — показатель по категориям

`barplot()` сравнивает числовой показатель между категориями.

```python
sns.barplot(
    data=data,
    x="level",
    y="average_score"
)
```

По умолчанию высота столбца показывает среднее значение `average_score` для каждой категории `level`.

То есть:

```text
countplot → сколько объектов?

barplot   → какое среднее числовое значение?
```

Дополнительное разделение:

```python
sns.barplot(
    data=data,
    x="level",
    y="average_score",
    hue="status"
)
```

---

## 14. `boxplot()` — сравнение распределений

`boxplot()` показывает распределение числового признака внутри категорий.

```python
sns.boxplot(
    data=data,
    x="level",
    y="average_score"
)
```

На каждом «ящике» можно увидеть:

- линию внутри — медиану;
- центральную часть — основную область значений;
- «усы» — диапазон обычных значений;
- отдельные точки — возможные выбросы.

`boxplot()` полезен, когда одного среднего недостаточно.

Например, у двух групп среднее может быть одинаковым, но разброс значений — совершенно разным.

## 15. `lineplot()` в Seaborn

`lineplot()` строит линейный график прямо из `DataFrame`.

```python
sns.lineplot(
    data=data,
    x="grade",
    y="average_score"
)
```

Если для одного `grade` есть много строк, Seaborn агрегирует их и показывает общую оценку для каждой точки `x`.

Дополнительная группировка:

```python
sns.lineplot(
    data=data,
    x="grade",
    y="average_score",
    hue="level"
)
```

Получится отдельная линия для каждого `level`.

Линейный график следует использовать, когда порядок `x` имеет смысл: время, возраст, номер класса, последовательные измерения.

---

## 16. `pairplot()` — быстрый обзор нескольких числовых признаков

`pairplot()` строит сразу много графиков для попарного сравнения признаков.

```python
sns.pairplot(
    data=data,
    vars=[
        "average_score",
        "hours_spent",
        "lessons_completed",
        "attempts"
    ]
)
```

Если выбраны четыре признака, Seaborn сравнит их друг с другом.

Например:

```text
hours_spent ↔ average_score
attempts ↔ average_score
lessons_completed ↔ hours_spent
...
```

На диагонали отображается распределение каждого отдельного признака.

Можно добавить категории цветом:

```python
sns.pairplot(
    data=data,
    vars=[
        "average_score",
        "hours_spent",
        "attempts"
    ],
    hue="level"
)
```

`pairplot()` полезен на этапе первого исследования данных перед машинным обучением.

## 17. Как выбрать тип графика

### Изменение по времени или другой упорядоченной оси

```text
line plot
```

Пример: средний балл по месяцам.

### Сравнение категорий

```text
bar / barplot
```

Пример: средний балл по курсам.

### Количество объектов в категориях

```text
countplot
```

Пример: сколько записей имеют каждый статус.

### Распределение одного числового признака

```text
hist
```

Пример: как распределены `average_score`.

### Связь двух числовых признаков

```text
scatter / scatterplot
```

Пример: связаны ли `hours_spent` и `average_score`.

### Сравнение распределений между категориями

```text
boxplot
```

Пример: отличается ли распределение баллов между уровнями.

### Быстрый обзор нескольких числовых признаков

```text
pairplot
```

## 18. График должен отвечать на вопрос

Перед построением графика полезно сформулировать вопрос.

Плохо:

```text
Построю какой-нибудь график average_score.
```

Лучше:

```text
Как распределены средние баллы?
```

→ гистограмма.

```text
Связано ли время обучения с результатом?
```

→ scatterplot.

```text
Какие курсы имеют более высокий средний балл?
```

→ barplot.

```text
Отличается ли разброс результатов на разных уровнях?
```

→ boxplot.

Хорошая визуализация не просто выглядит красиво — она помогает ответить на конкретный вопрос.

## 19. Мини-чеклист оформления

У графика должны быть понятны:

1. что изображено;
2. что находится по оси `x`;
3. что находится по оси `y`;
4. что означают цвета или маркеры;
5. в каких единицах представлены значения.

Минимум:

```python
plt.title("...")
plt.xlabel("...")
plt.ylabel("...")
```

Если присутствует несколько линий или групп:

```python
plt.legend()
```

## 20. Что не нужно изучать в этом блоке

Для текущего курса не нужны:

- тонкая настройка шрифтов и цветов;
- `GridSpec`;
- сложные аннотации;
- цветовые карты и `colorbar`;
- круговые диаграммы;
- 3D-графики Matplotlib;
- Mayavi;
- сложные `FacetGrid`, `PairGrid`, `JointGrid`;
- ручная настройка доверительных интервалов;
- KDE и другие способы оценки плотности.

Эти инструменты есть в книге, но для дальнейшей работы с данными и машинным обучением важнее уверенно выбирать и строить основные виды графиков.
